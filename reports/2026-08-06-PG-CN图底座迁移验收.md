## 操作

```bash
docker run -d --name voced-pg -e POSTGRES_USER=voced -e POSTGRES_PASSWORD=<your-password> -e POSTGRES_DB=voced_kg -p 5432:5432 postgres:16-alpine
python -m backend.kg.pg_store.migrate --clear --region CN
$env:SERVE_DEV_UI=1; $env:DATABASE_URL=postgresql://voced:<your-password>@localhost:5432/voced_kg
python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8088
```

自测：http://127.0.0.1:8088/admin-cytoscape （地区默认 CN）

## 4. 读法（一句话）

| 维/链 | 水平 | 短评 |
| --- | --- | --- |
| 专业 / 岗位 / 认证 **节点** | 高 | 目录级已落地 |
| 技能 **节点** | 高（量） | osta 标准批下后大幅上升 |
| 课目标 **节点** | 高 | 有课标 PDF 的专业较全 |
| 可学课 **节点** | 中低 | 830 条，多为检索入口非精品课详情 |
| 专→岗 | 中（职教较好） | 职教 74%，普本 37% |
| 专→课 | 中低 | 约四成专业有课标链 |
| 岗→技 | 中（岗覆盖） | 约三成岗位有标准链，边数已近万 |
| 技→可学课 / 真课详情 | 低 | taught_by 仅 33 |

## 5. 主要缺口（仍未「满覆盖」）

1. **约 40% 专业无专→岗**（普本无课标/无对口为主）。  
2. **约 58% 专业无专→课**（无对应课标 PDF）。  
3. **约 70% 岗位无 requires**（大典岗多于已颁布/可解析标准；部分码对不齐）。  
4. **可学资源弱**：精品课全量列表仍缺（H3）。  
5. **AI/规则边**仍需抽检（专→岗、证挂接、名称传播 requires）。

## 工程约定（避免返工）

1. **读 PG、写 SQLite 管道**：管道入库后需 `python -m backend.kg.pg_store.migrate --region CN`（或后续做增量 sync）；P1 建数可直接写 PG draft。  
2. **默认 region=CN**；EU/US 本阶段不交付。  
3. **每任务**：开干前你点头方案 → 我交付 → 你验收通过再下一项。  
4. **前端**：沿用 `admin-cytoscape` / 工作台壳，只加表单与审核列表，不重做 UI。

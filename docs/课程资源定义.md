# 课程维度定义（可学资源）

> 决策（已确认）：**用户要的 course = 能点开来学的资源**（视频、慕课页、公开 PDF 等，外链即可），  
> **不是**课标 PDF 里抄下来的课名标题 alone。

---

## 1. 两种对象

| 角色 `attrs.role` | 是什么 | `source_url` | 是否算主路径 course |
| --- | --- | --- | --- |
| **`learnable_resource`** | 一门可学的在线课/资源 | **必须可点开** | ✅ 是 |
| **`curriculum_catalog`** | 课标/培养方案中的课目名 | 可为课标门户/PDF | ❌ 目录用；展示应标「课目」 |

历史入库的课标解析课默认标 `curriculum_catalog`，避免被当成「点开就能学」。

---

## 2. learnable_resource 必填字段

| 字段 | 要求 |
| --- | --- |
| `name` | 课程/资源标题 |
| `source_url` | **可点击学习入口**（平台课页，非死链） |
| `source_system` | 如 `SMART_EDU` / `ICOURSES` / `MOOC_CN` |
| `confidence` | 官方目录 `official` / 平台公开页 `derived` |
| `attrs.resource_type` | `video_course` \| `mooc` \| `pdf` \| `mixed` \| … |
| `attrs.platform` | 平台中文名 |
| `attrs.is_free` | 是否免费开放（能判断则填） |
| `attrs.role` | 固定 `learnable_resource` |

可选：`attrs.major_keywords`、与 major/skill 的 `related_to` / `taught_by`。

---

## 3. 合规来源（优先）

| 平台 | URL 示例 | 用途 |
| --- | --- | --- |
| 国家智慧教育 · 职教 | https://vocational.smartedu.cn/ | 职教公开课/资源 |
| 国家智慧教育 · 高教 | https://higher.smartedu.cn/ | 慕课等 |
| 爱课程 / 中国大学 MOOC | https://www.icourses.cn/ | 精品在线开放课课页 |
| 课标 PDF | moe.gov.cn … | 仅 **catalog** 或证据，不当学习资源本体 |

禁止：付费墙内爬全文、盗版网盘 PDF、无许可商业课库整包。

---

## 4. 与课标的关系

```
专业 --related_to--> 课目(catalog)     # 课标「应开什么课」
专业 --related_to--> 可学资源          # 有公开课则直接挂
课目 --related_to--> 可学资源          # 名称/关键词对齐后挂（derived）
技能 --taught_by--> 可学资源           # 有依据时
```

完整交付 = **规模化可学资源（有 URL）** + 课目标规模化（目录对齐）。

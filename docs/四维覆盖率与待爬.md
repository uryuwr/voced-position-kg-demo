> 统计日：2026-08-13。库：`kg_node` / `kg_edge`，`region=CN`。  
> 口径：**未归档** = 管理台可见；**published** = 前台可见。archived 不计入覆盖。  
> 本期主路径：行业 · 专业 · 岗位 · 技能。课程 / 认证只作对照，不作为本期交付缺口。

一句话：**目录层（专业 / 岗位 / BOSS 行业 / 已颁布技能标准 PDF）基本齐；边层是短板——岗→技只覆盖约三成岗位，专→技几乎没有，行业树被归档，岗→行业又稀又全是 AI 边。**

### 2.1 专业 → 行业（单独拆开）

专业与行业之间**只有这一种边**：`belongs_to`（major → industry，`structure_layer=tree`）。没有 industry → major 的反向边，也没有 `related_to` / `covers` 挂在这两类节点上。

| 层次 | 专业数 | 有行业边 | 覆盖 | 无边 |
| --- | ---: | ---: | ---: | ---: |
| 高职专科 | 775 | 578 | **74.6%** | 197 |
| 职业本科 | 270 | 198 | **73.3%** | 72 |
| 中职 | 361 | 242 | **67.0%** | 119 |
| 普通本科 | 875 | 553 | **63.2%** | 322 |
| 手工 | 2 | 1 | — | 1 |
| **合计** | **2283** | **1572** | **68.9%** | **711** |

来源：`source_system=HEURISTIC` 1570 条（`scripts/link_major_industry_heuristic.py`，教育部门类关键词 → BOSS 行业名子串），手工 2 条。跑脚本时 `unmatched=711`，和现在无边数对得上，之后没再扩词典。

行业侧极不均：149 个行业里 **只有 44 个接到过专业**（105 个零专业）。Top 把大量专业吸走——「企业服务」280、「广告/传媒/文化/体育」250——是词典把「管理→企业服务」「艺术→文娱」打得太宽。互联网、人工智能、农/林/牧/渔、学校/学历教育 等子类 **0 条专→行**。

无边样本以普本文史哲、小语种为主（世界史、伦理学、丹麦语…），词典没有对应键。职教缺边则是门类字符串脏（带制表符/层次后缀）没命中。

## 3. 覆盖率怎么读

### 3.1 目录覆盖（该采的官方清单）

| 底库 | 目标 | 已入库 | 结论 |
| --- | ---: | ---: | --- |
| 教育部专业目录（四层） | 2281 | 2281 | 齐 |

| BOSS 行业树 | 149 | 149 | 齐 |

前台更严：published 专业 1935 中 1360 有专→岗（**70.3%**）；published 岗位 1331 中 491 有岗→技（**36.9%**）。

孤儿（四维活边一条都没有）：专业 380、岗位 359、技能档 6016（多为「标准里有、当前岗位不要求的档」）、行业 21（4 个大类 + 17 个无岗无专业的子类）。

### 3.3 边质量

- 专→岗：**68% official**（课标职业面向），31% `ai_inferred`，未抽检（H4）。
- 岗→技活边：**88% official**；AI 传播大多已归档。
- 专→行业：1572 条全是门类词典 `derived`，一专业一条；149 行业里 105 个接不到任何专业。无官方对照表。
- 岗→行业：**几乎全是招聘站关键词 AI 边**，且只覆盖 19% 岗位。
- 专→技：没有生产数据。

## 4. 还要爬什么

按「没有官方源就爬不到」分开。

### 4.1 仍值得爬 / 补文件

| 优先级 | 事项 | 现状 | 动作 |
| --- | --- | --- | --- |
| P0 | **OSTA 技能标准增量** | 702 已全下（2026-08-06）。人社厅发〔2026〕27 号等新标准还在往目录里加 | 定期 `harvest_osta_skill_api` + `batch_download_osta_catalog_pdfs` + 重解析 |
| P0 | **课标 PDF 残余**（H1） | 736 / ~758 | 重跑 `batch_download_moe_standards`，补失败 URL |

### 4.2 不是爬的问题（连边 / 治理）

| 优先级 | 事项 | 说明 |
| --- | --- | --- |
| P0 | **`covers` 专→技** | 课标「规格/能力」还没规模化建边，生产 0 条 |
| P0 | **职教专业无专→岗 365 条** | 课标职业面向解析漏码 + 无课标专业。先抠已有 736 份 PDF，再补词典 |
| P0 | **普本无专→岗 556 条** | 没有课标可对码，只能简介/就业面向 + 抽检，不能指望再爬一份官方全表 |
| P1 | **岗→行业 81% 空** | 现有 1159 条是 AI 关键词，先抽检再扩，别盲目加爬 |
| P1 | **恢复或重建行业 `parent_of`** | 149 个节点还在，134 条树边被归档，图上大类挂不住子类 |
| P1 | 回写 `skill_key` | 8889 个等级节点都能从 `occupation_code + skill_name` 生成，不需要重爬 |
| P1 | 专→行业词典扩（余量 D1） | 31% 专业还没挂上行业 |
| P1 | AI 专→岗抽检（H4） | 2168 条 `ai_inferred` |
| P2 | `advances_to` | 大典里没有现成晋升表，要规则/人工 |
| P2 | PDF 等级描述回写 | 8889 里只有 2492 有 `level_descriptions` |
| — | 大典无国标的 ~1200 岗 | **源站无标准，爬不到**。不要为凑覆盖率去扒招聘 JD |

### 4.3 明确不做 / 后置

- 招聘站职位详情、简历（合规禁止）。
- 课程 / 认证扩量（本期四维范围已后置；课目标 1.6 万已在库）。
- 研究生专业目录。
- EU / US：当前这套 PG **只有 CN**。ESCO / O\*NET 原始包在 `data/raw/`，未进本库。

## 5. 建议下一轮顺序

1. 课标残余 PDF + 职业面向补解析 → 职教专→岗往 85%+ 推。

5. 智联行业、可学资源、缺工 100：有人值守再开。

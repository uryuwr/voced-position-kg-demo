# 三区数据范围：职业教育 / VET / CTE 相关

> **统一约束（CN / EU / US 相同）：** 图谱服务的是  
> **职业教育（及与之并列的应用型/职业导向学历教育）→ 就业岗位 → 技能 → 课程 → 认证**  
> 不是「全职业百科」或「纯学术学科树」。  
> 中国另确认：**普通本科与高职都算专业侧**（见 §2）。

---

## 0. 三国概念对齐

| 区 | 本地概念 | 本项目怎么用 |
| --- | --- | --- |
| **CN** | **职业教育**（与普通教育并列的类型）+ 应用向/普通本科就业链 | 中职/高职专科/职业本科 + **普通本科**专业；岗位/技能/课/证服务该培养链 |
| **EU** | **VET**（Vocational Education and Training）+ EQF 职业导向资格 | 岗位/技能以 **ESCO** 为官方底座（VET–劳动力市场共同语言）；专业/课/证优先 **VET / EQF 职业资格 / Europass 可挂载** 公开源，不铺纯学术学位全库 |
| **US** | **CTE**（Career and Technical Education）+ 社区学院/技术教育路径 | 岗位/技能以 **O\*NET** 为官方底座；专业优先 **CIP 中 CTE/职业相关**；认证/课程优先 **行业认可证 + 公开 CTE/社区学院课元数据**，不铺全量文理博雅专业 |

目标链路（三区共用本体）：

```
专业(major) → 岗位(occupation) → 技能等级(skill_level) → 课程(course) → 认证(credential)
```

## 1. 中国 CN（已确认）

### 1.1 概念

| 概念 | 含义 |
| --- | --- |
| 职业教育 | 与普通教育同等重要的教育类型，培养技术技能人才 |
| 普通本科 | 法律上属普通教育类型，**本项目专业侧仍收录**（你确认） |

### 1.2 五维

| 维度 | 收 | 不收/弱推 |
| --- | --- | --- |
| 专业 | 中职、高职专科、职业本科、**普通本科** | 研究生目录全量后置 |
| 岗位 | 大典细类底库；推荐降权机关/军队/保安保洁等 | 主路径靠专→岗证据 |
| 技能 | 国家职业（技术）技能标准 **规模化** | 无关工种不灌 |
| 课程 | 职教课标 **规模化**；普本仅可挂专业的公开依据 | 不铺全校课表 |
| 认证 | 1+X 主名单等 | 无关准入资格后置 |

`education_type`：`vocational` | `general`（标签，不删普本）。

## 2. 欧盟 EU · VET 相关

### 2.1 官方锚点

- **VET**：欧盟职业与培训政策主概念（初始/继续 VET，对接就业）。  
- **ESCO**：欧委会技能–能力–资格–职业分类，服务劳动力市场 **与教育培训对齐**（含 VET）。  
- **EQF / Europass / 国家资格框架**：职业导向资格与学习成果描述。

### 2.2 五维口径

| 维度 | 收 | 说明 |
| --- | --- | --- |
| **专业 major** | 与 **VET 课程/职业资格** 可对齐的公开专业或资格教育条目 | **不**以「全欧所有大学文理专业」为目标；优先 ISCED/国家 VET 目录、EQF 职业资格侧 |
| **岗位 occupation** | **ESCO occupations**（官方全量可作底库） | 主路径：与 VET/资格有技能关系或可被培养路径挂接的职业；纯管理/政务等可降权推荐（同 CN 逻辑） |
| **技能 skill_level** | **ESCO skills** + occupation–skill 官方关系 | 技能等级：有官方 level/essential 则写入 attrs；无等级则标 `required/essential` 等，不强造 L1–L4 |
| **课程 course** | 公开 **VET 课程/模块** 元数据（有 URL 或官方编号） | Cedefop / 国家开放目录 / 许可允许的开放课；禁止无许可商业课库 |
| **认证 credential** | 国家资格框架中 **职业资格**、行业认证公开条目 | 与 Europass/ESCO qualifications 可连则连 |

### 2.3 现状与改造方向

| 现状 | 问题 | 改造 |
| --- | --- | --- |
| ESCO 职业+技能+requires 已有一定规模 | 更像**全劳动力市场**，未标「VET 相关」 | 保留 ESCO 底座；打 `vet_relevant` / 推荐档；补 **VET 专业与资格** 维 |
| 专业/课程/认证弱 | 五维不齐 | **P0 补 VET 侧 major/course/credential** 公开源 |

## 3. 美国 US · CTE 相关

### 3.1 官方锚点

- **CTE**（Career and Technical Education）：中学与中学后职业与技术教育（Perkins 等政策框架）。  
- **CIP**：教学项目分类；CTE 项目用 CIP 标识「为哪些职业做准备」。  
- **O\*NET**：职业与技能矩阵（就业侧官方底座）。  
- 行业认证 / CareerOneStop 等公开目录：就业与证书衔接。

### 3.2 五维口径

| 维度 | 收 | 说明 |
| --- | --- | --- |
| **专业 major** | **CIP 中 CTE/职业导向项目** + 与 CTE 路径衔接的副学士/证书项目等 | 可含部分应用型学士；**不**以「全部文理博雅专业」为全量目标（与 CN「普本也收」对齐时：可收 **应用/STEM/职业导向** 本科 CIP，文理纯学术可降权或后置） |
| **岗位 occupation** | **O\*NET occupations** 底库 | 主路径：有教育/培训要求、与 CTE 集群或 CIP 可映射的职业；推荐降权与 CTE 弱相关的岗位 |
| **技能 skill_level** | O\*NET Skills/Knowledge/Abilities + Level/Importance | 已是「技能+等级」形态，保留并做 CTE 相关岗位过滤 |
| **课程 course** | 公开 CTE/社区学院/可访问 MOOC 元数据（必须有 URL） | 不灌封闭 LMS |
| **认证 credential** | 行业认证、执照公开目录（CareerOneStop 等） | 与职业/CIP 有公开对应优先 |

### 3.3 现状与改造方向

| 现状 | 问题 | 改造 |
| --- | --- | --- |
| O\*NET 职业+技能+requires 较全 | 全劳动力市场，非 CTE 视角 | 底库可留；**标签 + 主路径过滤**；补 **CIP/CTE 专业与认证** |
| 专业/课程/认证弱 | 五维不齐 | **P0 补 CIP（CTE 相关）+ 公开认证** |

## 4. 三区统一原则

1. **专业侧 = 培养入口**（职教/VET/CTE + 各国确认的应用向学历）。  
2. **岗位/技能 = 就业与能力**（ESCO/O\*NET/大典），**主视图不等于全库裸奔**。  
3. **课程/认证 = 学与证**，必须 **可溯源 URL 或官方编号**。  
4. **边必须有 evidence**；无官方表则 derived/AI + 抽检，不把演示种子当最终交付。  
5. **完整目标 = 规模化覆盖 + 主链可走**，不是「每区两三个样例」。

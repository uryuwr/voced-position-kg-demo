## 一、职业教育面临的根本挑战

职业教育正在经历「格局性变化」——数字化转型已从「可选项」变成「必答题」。

### 政策背景：职业教育「必答题」时代

| 政策文件 | 核心要求 | 对院校的影响 |
| --- | --- | --- |
| 新双高计划考核 | 不再比硬件，重点核查产教融合、数字化教学、就业质量 | 数字化和 AI 成为硬性考核指标，直接影响拨款和评级 |
| 专业红黄牌机制 | 低就业率专业红牌停招；2026 年新增 27 个专业 | 对产业数据驱动的专业评估形成刚需 |
| AI 赋能职教（硬性考核） | 全师生 AI 通识课程；AI 嵌入备课、教学、学情诊断 | 教师数字素养、AI 教学应用纳入职称评审核心指标 |
| 产教融合体系重构 | 企业从「合作方」转为「人才培养核心主体」 | 需要数据平台实现校企人才精准匹配 |
| 岗课赛证融通 | 专业、课程、教材、教师、实训五大要素一体化改革 | 需要岗位-课程-证书精准映射平台 |

### 核心数据：现实困境重重

| 挑战 | 核心数据 | 典型声音 |
| --- | --- | --- |
| 专业与产业脱节 | 智能制造岗位技能每 18 个月显著变化，教材更新周期 3–5 年 | 「辛苦教了三年，企业说学的东西用不上」 |
| 学生双重困境 | 60% 双学率；30% 心理问题；课堂专注力不足 15 分钟 | 「上课 15 分钟就走神，60% 学生在刷手机」 |
| 教师负担过重 | 日均处理 15+ 碎片任务；班主任手机 24h 在线 | 「白天行政坐班，晚上才轮到备课」 |
| 就业焦虑严重 | 中职应届平均月薪 3,200 元；对口就业率不到 50% | 「毕业能不能找到工作？心里一点底都没有」 |
| 产教融合走过场 | 签 20 几份协议，真正参与教学的企业不到 3 家 | 「想引入 AI，不知道怎么搞、谁来搞」 |

## 二、解决方案概览

不是教学工具升级，而是**职业教育人才培养的新基础设施**。

> **产业需求洞察 + AI 驱动的人才培养 + 可量化就业质量 = AI 职业教育**

| 维度 | 传统模式 | AI 职业教育 |
| --- | --- | --- |
| 专业建设 | 凭经验设专业，审批周期长 | 基于产业数据的精准规划，实时更新 |
| 备课教研 | 教材落后 3–5 年，教师疲于应付 | AI 追踪行业变化，智能备课 + 协同教研 |
| 课堂教学 | 学生专注力不足 15 分钟，教师单向输出 | AI 实时分析学情，智慧课堂互动 |
| 实训教学 | 设备老旧、场景简化 | AI 模拟真实工作场景，沉浸式实训 |
| 师资发展 | 教师被行政淹没，无暇提升 | AI 接管重复工作，释放教师专业成长空间 |
| 校园生活 | 活动 / 竞赛 / 训练营缺系统化管理 | 全流程数字化 + 智能化管理与评估 |
| 产教融合 | 签协议走过场 | 数据驱动的校企精准对接 |
| 就业服务 | 毕业才找工作，对口率不到 50% | 全周期职业能力培养，精准匹配就业 |

---

## 三、核心价值主张

**让专业建设可见，让课程体系可规划，让就业质量可衡量，让学生成长可感知，让院校具备自主 AI 能力。**

——不是教学工具的升级，而是职业教育人才培养的新基础设施。

## 四、十四大业务场景

平台覆盖从专业建设到就业服务的全链条，深入校园教学、校园生活、产教融合的每一个环节。每个场景都直接对应当前政策要求。

### ▶ 教学核心

#### 场景 1：产业-人才 Gap 分析

| 字段 | 内容 |
| --- | --- |
| 使用者 | 教务处长 / 专业带头人 |
| 解决问题 | 专业设置凭经验，等获批时行业已变；红黄牌机制下缺数据支撑可能停招 |
| 方法 | 知识图谱自动分析区域产业需求与培养能力匹配度 |
| 产出 | 产业人才需求报告、专业优化建议 |
| AI 赋能 | 覆盖 5,368 职业、62,580 行技能矩阵，自动追踪岗位技能变化 |
| 对应政策 | 教职成〔2026〕1 号「以产定教」、红黄牌机制、新双高专业适配度考核 |

#### 场景 2：智能备课与协同教研

| 字段 | 内容 |
| --- | --- |
| 使用者 | 教师 / 教研组 |
| 解决问题 | 教师日均 15+ 碎片任务，备课时间被严重挤压；教研组缺乏协同工具，跨校区教研难以开展 |
| 方法 | AI 辅助生成教案、课件、实训项目；支持集体备课、听课评课、跨校区协同教研 |
| 产出 | 智能教案、协同教研记录、跨校区资源共享 |
| AI 赋能 | AI 自动匹配课标要求，生成教案初稿；智能推荐行业最新案例 |
| 对应政策 | 五大要素一体化改革、教师减负提质、教师数字素养纳入职称评审 |

#### 场景 3：智慧授课与课堂互动

| 字段 | 内容 |
| --- | --- |
| 使用者 | 教师 / 学生 |
| 解决问题 | 课堂专注力不足 15 分钟，78% 学生偷用手机；教师无法实时了解学生听课状态 |
| 方法 | 智能签到、实时互动（问答 / 投票 / 抢答）；AI 分析学生参与度和专注度 |
| 产出 | 课堂互动数据报告、学情实时仪表盘 |
| AI 赋能 | AI 实时分析学生听课状态，即时答疑和知识点标注 |
| 对应政策 | 过程性评价体系、AI 嵌入教学全流程、数字化成长画像 |

## 五、六大用户角色

每一类用户都有其真实的工作场景和痛点，平台针对每一类用户提供专属价值。

| 角色 | 核心困境 | 平台价值 |
| --- | --- | --- |
| 学生 | 60% 双学，30% 心理问题，「习得性无助」，深层自卑 | AI 学习教练用学生能接受的方式教学，微目标重建信心 |
| 教师 | 日均 15+ 碎片任务，「双肩挑」行政压力，AI 应用停留表面 | AI 接管备课 / 批改 / 报表，释放教师专业发展时间 |
| 班主任 / 辅导员 | 变「监工」，管耳钉 / 手机 / 宿舍冲突，情感劳动过载 | 学生行为数据仪表盘 + 心理预警，从「监工」回归「导师」 |
| 教务 / 院系管理层 | 缺数据支撑决策，无法量化培养质量 | 产业-人才 Gap 分析 + 教学评估 + 就业 ROI 量化 |
| 校企合作处 | 「学校热企业冷」，无法用数据证明产教融合实效 | 人才匹配报告 + 合作效果追踪，用数据说服企业 |
| 院校领导层 | 新双高考核压力前所未有，办学质量难以量化 | 全局数据仪表盘 + 办学质量报告，「拿着数据去汇报」 |

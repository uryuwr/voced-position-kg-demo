# 部署与生产鉴权（P3-4）

## 依赖

- PostgreSQL（`DATABASE_URL`）
- Python 3.11+：`pip install -r backend/requirements.txt`
- 可选 AI 网关：`LLM_BASE_URL` + `GITHUB_TOKEN` + `LLM_MODEL`

## 环境变量

配置在 **backend 包内**（独立部署不依赖仓库根）：

- 模板：[`backend/.env.example`](../backend/.env.example)
- 本地：`cp backend/.env.example backend/.env` 后编辑
- 加载：`backend/settings.py`（`backend/.env` 覆盖 monorepo 根兜底）

| 场景 | 建议 |
| --- | --- |
| 本地开发 | `AUTH_BYPASS=1`，`SERVE_DEV_UI=1`，`REVIEW_REQUIRED=0` |
| 生产 | `AUTH_BYPASS=0`，配置 `SDP_APP_ID` 与 UC；业务请求带 UC MAC `Authorization` |

## 启动

```bash
# 仓库根
export PYTHONPATH=.
# Windows: $env:PYTHONPATH = (Get-Location).Path
python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8088
```

- Swagger：`http://<host>:8088/docs`
- 健康：`GET /health`（含 `postgresql`、`ai_gateway`）
- 管理台：`/admin-console`（需 `SERVE_DEV_UI=1` 或反向代理静态）

## Docker

见 `backend/Dockerfile`。镜像内不应打包 `.env` / `data/raw`。

## 生产检查清单

- [ ] `AUTH_BYPASS=0`
- [ ] UC / SDP 可登录，前端 MAC 签名含完整 query
- [ ] PG 连接池与备份
- [ ] AI 网关仅内网可达（如需诊断 Agent）
- [ ] 日志不含完整 token

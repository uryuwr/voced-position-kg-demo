# 市面「职业/技能/知识图谱」产品怎么做界面？

> 目的：对齐「用户想要的效果」——看真实产品怎么呈现，而不是只盯我们自己的多列表页。

---

## 1. 先分清：两类完全不同的「图谱产品」

| 类型 | 用户是谁 | 界面长什么样 | 代表 |
| --- | --- | --- | --- |
| **A. 职业/学习路径探索** | 学生、求职者、教务 | 搜索 → 岗位/专业详情页 → 技能清单、薪资、课程推荐；偶有路径图 | My Next Move、CareerOneStop、Coursera 路径、roadmap.sh |
| **B. 图数据库/知识图谱工具** | 数据/分析/研发 | 节点连线、搜索展开、Cypher/筛选 | Neo4j Browser/Bloom、AWS Graph Explorer |

你们业务文案是 A（职业教育五维），技术底座是图（接近 B）。  
**市面成功产品几乎都把 A 做给人看，把 B 藏在后面给系统和 AI。**

## 2. 可直接点开的体验界面（建议你先点这些）

### 2.1 职业探索（最接近「专业→岗→技能」）

| 产品 | 链接 | 界面怎么玩 | 实现要点 |
| --- | --- | --- | --- |
| **My Next Move**（美国劳工部/O\*NET 亲民版） | https://www.mynextmove.org/ | 搜职业 / 按行业逛 / 兴趣测评 → **一页岗位档案**（任务、技能条、薪资、知识） | **不是网状图**；技能用进度条/列表；入口极简单 |
| **O\*NET OnLine**（专业版） | https://www.onetonline.org/ | 搜岗位 → 详细报告（技能、知识、能力、相关职业） | 多 Tab/分区详情页；数据即 O\*NET |
| **CareerOneStop** | https://www.careeronestop.org/ | 职业、技能、证书、培训一站式 | **证书/培训分频道**；工具型导航 |
| **Kickresume AI Career Map** | https://www.kickresume.com/en/ai-career-map/ | 起点→目标，地图上多个角色路径 + 已有技能/待学技能 | **路径地图** + 技能差距列表 |

### 2.2 学习路径 / 技能树（最接近「技能→课」）

| 产品 | 链接 | 界面怎么玩 | 实现要点 |
| --- | --- | --- | --- |
| **roadmap.sh** | https://roadmap.sh/ | 选方向 → **可点击技能树/路线图** → 节点连学习资源 | 视觉是「路线图」不是力导向；节点可勾选进度 |
| **Coursera / 各类 Career Path** | 各平台 Career Academy | 岗位目标 → 课程序列 | **步骤条/时间线**；转化率优先 |

### 2.3 企业职业路径（HR）

| 产品 | 说明 | 界面特点 |
| --- | --- | --- |
| **Visier Career Paths** | 员工从当前岗到下一岗 | 角色节点 + 晋升/平行移动，带时间估计 |
| **Degreed / Cornerstone 等** | 技能本体 + 学习 | 技能档案、缺口、推荐学习，图多为后台 |

### 2.4 图工具（别当 toC 主界面）

| 产品 | 链接 | 说明 |
| --- | --- | --- |
| **Neo4j Bloom** | 商业，需 Neo4j | 搜索展开，比 Browser 友好，仍是「图探索」 |
| **AWS Graph Explorer** | https://github.com/aws/graph-explorer | 开源：搜索节点、展开邻居、无查询语言 |

### 2.5 国内相关

| 方向 | 说明 |
| --- | --- |
| 招聘侧「职位-技能」 | 智联/Boss 等是 **职位详情 + 技能标签**，不是知识图谱大屏 |
| 职教「能力图谱」文献/院校方案 | 多为 **层级图：专业→岗位→能力→课/知识点**（流程图式），纸质/PPT 也常见 |
| 部分 SaaS「招聘知识图谱」 | B 端演示多，公开 toC 可点界面较少 |

## 3. 这些产品「实现」上的共性（界面层）

几乎都遵守：

1. **入口是目标，不是图画布**  
   「我想当… / 搜专业 / 搜岗位」，不是一上来满屏点线。

2. **主载体是「详情页 + 清单」**  
   - 岗位页：做什么、要什么技能（可排序/分级）、薪资、相关职业  
   - 技能用 **条、星级、L1–L4 标签**，不是边缠在一起  

3. **路径是第二条主叙事**  
   当前 → 下一岗；或 课1→课2→课3；或 roadmap 节点流。  
   一次突出 **1 条主路径**，其它折叠。

4. **关系探索是高级功能**  
   「相关职业」「相似岗位」用列表或小图；全库网状图几乎不对普通用户默认打开。

5. **认证/课程是独立模块**  
   CareerOneStop 等：**Careers / Skills / Training / Credentials 分栏导航**，不会混成一列「资源」。

## 4. 和我们五维的对应（你要的产品更像谁）

| 五维 | 市面通常怎么露脸 |
| --- | --- |
| 专业 | 搜索/专业库入口；院校方案里的「能力图谱」顶层 |
| 岗位 | **My Next Move 式岗位档案页** |
| 技能等级 | 岗位页内技能表 + 重要度/等级 |
| 课程 | 学习路径步骤 / 推荐课列表 |
| 认证 | 独立「证书」区或路径终点 |

**后端仍可用 Neo4j**；前端主流是：

```text
搜专业/岗位
  → 岗位列表
    → 点进「岗位档案」（技能表 + 相关课 + 相关证）
    → 可选「培养路径」时间线
    → （高级）关系小图
```

而不是默认「五列管理台」或「Neo4j 力导向」。

## 5. 建议你怎么「选型感」

| 若你更想要… | 去点这些 | 我们前端应长什么样 |
| --- | --- | --- |
| 官方职业数据怎么给人看 | My Next Move、O\*NET | 岗位档案 + 技能表 |
| 学习路线怎么给人看 | roadmap.sh | 可点路线图/步骤 |
| 转岗/下一跳 | Kickresume Career Map、Visier 类 | 路径地图 + 技能差距 |
| 图数据库怎么给人探索 | Bloom / Graph Explorer | 仅「高级」 |

**请你先点 20 分钟：**

1. https://www.mynextmove.org/ （搜 software）  
2. https://www.onetonline.org/ （点进一个职业报告）  
3. https://roadmap.sh/ （点 frontend 或 AI）  
4. https://www.careeronestop.org/ （看证书/培训入口）  

然后告诉我最接近「你想要的感觉」的是哪一个（或截图描述），再按那个范式改我们的 HTML——比继续猜线框更准。

---

## 6. 一句话

市面成熟的「职业/技能」产品，**体验界面几乎都是：搜索 + 档案页 + 清单/路径图**；  
**节点连线大图**是图平台给专家用的。  
我们库是图谱，**脸应做成 My Next Move / roadmap 一类**，而不是 Browser。

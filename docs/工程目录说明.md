# 工程目录说明

> 2026-08-06 起：**爬虫 / 后端 / 前端** 分目录隔离。

## 顶层

| 目录 | 职责 | 部署 |
| --- | --- | --- |
| `backend/` | **独立 API**（唯一对外服务交付物） | SDP/Docker |
| `crawlers/` | 下载、解析、建边 | 离线任务，不进 API 镜像 |
| `frontend/` | 开发者自测 HTML | **不部署**；`SERVE_DEV_UI=1` 才挂载 |
| `schemas/` | 本体与来源登记 | 可随 backend |
| `data/` | 原始文件与图库 | 卷/外部库 |
| `pipelines/` | 兼容 shim | 勿写新逻辑 |

正式前端工程 **只 HTTP 调 backend**，不 bundling 本仓库 `frontend/`。

## 依赖方向

```
frontend  ──HTTP──▶  backend
crawlers  ──import──▶ backend.kg（graph_store / paths / provenance / neo4j migrate）
backend   ──不依赖──▶ crawlers
```

## 兼容

```bash
# 新
python -m crawlers.cn.ingest_majors
python -m backend.kg.neo4j_store.migrate
uvicorn backend.api.main:app --port 8088

# 旧（shim）
python -m pipelines.cn.ingest_majors
uvicorn pipelines.api.main:app --port 8088
```

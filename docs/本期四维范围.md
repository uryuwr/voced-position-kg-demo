> 更新：2026-08-06

## 主路径

```
行业 (industry) ──parent_of──▶ 子行业
岗位 (occupation) ──belongs_to──▶ 行业
专业 (major) ──prepares_for──▶ 岗位
岗位 ──requires──▶ 技能 (skill_level)
```

### 命令

```bash
# 拉行业树并入库
python -m pipelines.cn.ingest_boss_industry

# 接口失败时人机协同
python -m pipelines.cn.harvest_boss_industry_playwright --headed --wait-login
# 验证完成后：New-Item reports/h2_login_ready.flag

# 岗→行业
python -m pipelines.cn.link_industry_occupations

python -m pipelines.neo4j_store.migrate
```
